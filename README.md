# LADPORTAL PLC Ladder Logic Simulator

LADPORTAL is a portable Windows desktop application for learning and demonstrating PLC ladder logic. It is designed as a student-friendly simulator for building basic ladder rungs, mapping inputs and outputs, testing logic flow, and explaining industrial automation concepts without needing physical PLC hardware.

## Purpose

Many students understand PLC theory but do not always have access to real PLC panels, licensed vendor software, or industrial training hardware. LADPORTAL reduces that gap by giving students a simple offline environment for practice, explanation, and portfolio demonstration.

This project can be used for:

- PLC ladder logic learning
- Beginner automation workshops
- I/O mapping demonstrations
- Simulation of basic control sequences
- Interview and portfolio discussion for industrial automation roles

## Main Features

## Important Note

LADPORTAL is a learning and simulation project. It is not a certified replacement for industrial PLC engineering software such as Siemens TIA Portal, CODESYS, or Rockwell Studio 5000.

## Suggested Demo Flow

1. Open the portable Windows application.
2. Create or load a basic PLC ladder logic example.
3. Define inputs and outputs.
4. Run the simulation.
5. Explain how contacts, coils, and state changes affect the output.
6. Discuss how the same control idea maps to real machines such as conveyors, sensors, and actuators.
